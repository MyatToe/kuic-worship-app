# Your own projector backgrounds

Put pictures here (`.jpg`, `.png` or `.webp`, ideally 1920×1080), then run:

```sh
node tools/build-index.mjs
```

They appear in **⚙ Settings → Projector → Background** on every device, after you commit and push.
Only use pictures you have the right to use: your own photos, public-domain art (e.g. from artvee.com) or licensed images.
